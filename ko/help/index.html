최신 업데이트

버전 0.4.9

현재 버전

2026년 9월 29일 출시

패널이 이제 Mac용 Kapture Pro와 같은 방식으로 움직입니다. 캡처 방식을 바꾸거나 설정을 열거나 기록의 페이지를 넘길 때 무엇이 달라졌는지 스스로 보여 주며, 속도는 그대로입니다.

  • 선택 표시가 따라 움직입니다. 전체 페이지와 영역 선택 사이, 또는 보관됨과 삭제됨 사이를 오갈 때 하나의 표시가 미끄러지듯 이동합니다. 한 버튼에서 다른 버튼으로 툭 옮겨가지 않습니다.
  • 더 부드러운 전환. 캡처 방식, 설정, 기록, 페이지 이동에 모두 적용됩니다. 페이지를 넘기면 넘어가는 방향으로 움직입니다.
  • 정돈된 움직임. 상태 메시지와 삭제 대화상자, Kapture Pro 안내에 적용했습니다.
  • 더 부드러운 테마 전환과 버튼을 누를 때의 가벼운 반응.
  • 동작 줄이기 설정을 따릅니다. 시스템에서 움직임을 줄이도록 설정하면 전환이 짧은 페이드로 바뀌고 미끄러지는 움직임이 사라집니다. 모든 기능은 그대로 작동합니다.
  • 빠르고 절제되게. 튕기는 움직임이 없고, 기록의 행이 하나씩 차례로 나타나지도 않습니다.
  • 최근의 설정 작업을 포함합니다. 언어와 도움말 항목 및 각 아이콘, 그리고 이 사이트의 다국어 도움말과 개인정보 페이지가 함께 담겼습니다.

이전 업데이트

버전 0.4.8 2026년 9월 25일

Kapture가 다섯 개 언어를 지원하고, 기록에서 아직 남아 있는 캡처와 사라진 캡처를 나눠 보여 주며, 새로 만든 스크린샷마다 어떻게 찍었는지에 대한 작은 기록이 함께 담깁니다.

  • 다섯 개 언어. 사이드 패널을 English, Español, 简体中文, 한국어, 日本語로 사용할 수 있습니다.
  • 언어 설정. 설정에 언어 항목이 생겼습니다. 기본적으로 브라우저 언어를 따르며, 선택한 언어는 그대로 유지됩니다.
  • 기록의 보관됨·삭제됨 탭. 파일이 기기에 남아 있는 캡처와 파일이 사라진 기록을 나눠서 보여 줍니다.
  • 기록 페이지당 10개 항목으로 늘었습니다. 이전에는 6개였습니다.
  • 완료 메시지는 몇 초 뒤 사라집니다. 오류와 경고는 다른 메시지가 나타날 때까지 남아 있습니다.
  • 이미지 안에 담기는 캡처 기록. 새로 만든 PNG와 JPEG 캡처에는 페이지 주소, 사이트 이름, 뷰포트, 캡처 방식, 캡처 시각이 파일 안에 함께 저장됩니다. 이 정보는 기기에만 남습니다.
  • 현재 브라우저 뷰포트 수정. 이제 페이지가 실제로 그려진 레이아웃 너비를 기록하므로, 스크롤바가 보이는 페이지가 몇 픽셀 더 넓게 기록되지 않습니다.
  • Kapture Pro 안내. Mac용 Kapture Pro를 소개하는 알림으로, 닫을 수 있으며 kaptapp.com 링크가 있습니다.
  • 정돈된 하단 영역. 왼쪽에 설정과 개인정보, 오른쪽에 kaptapp.com이 있습니다.
  • 뷰포트 라벨이 기기 이름을 표시합니다. 픽셀 너비를 반복해서 보여 주지 않습니다.
  • Kapture Pro에 더 가깝게. 패널 여백과 컨트롤, 기록 카드를 Mac 앱에 맞추고 상단과 하단에 은은한 Kapture 청록색을 더했습니다.
  • 개선된 명암비. 라이트 모드의 보조 텍스트를 더 어둡게 조정해 4.5:1 명암비를 만족합니다.
버전 0.4.7 2026년 9월 16일

저장 경로가 스스로 복구되고, 확인 메시지가 실제 결과를 정확히 알려 주며, 여러 장으로 나뉜 캡처의 번호가 올바르게 매겨집니다.

  • 이전 저장 폴더 정리. Kapture를 프로젝트 이름으로 저장하던 예전 버전의 설정을 한 번만 바로잡아, 캡처가 더 이상 Downloads/Kapture/Kapture에 저장되지 않습니다.
  • 정확한 확인 메시지. 완료 메시지가 파일이 실제로 저장된 폴더를 알려 줍니다.
  • 분할 캡처의 연속 번호. 여러 이미지로 나뉜 캡처의 파일 이름에서 번호가 건너뛰지 않습니다.
  • 정식 도움말과 문구가 남아 있던 시제품 문구를 대체했습니다.
버전 0.4.6 2026년 9월 16일

기준이 되는 버전입니다. Chrome 웹 스토어에 공개된 빌드를 그대로 버전 관리에 담아, 이후 모든 릴리스를 이 버전과 비교할 수 있습니다.

  • 전체 페이지와 영역 선택 캡처를 PNG, JPEG, PDF로 저장.
  • 현재 브라우저와 휴대폰, 태블릿, 두 가지 데스크톱 뷰포트 프리셋.
  • 열기와 삭제가 가능한 기기 내 캡처 기록.
  • Kapture 폴더에 저장하며, 프로젝트 하위 폴더를 선택적으로 사용.

Kapture 사용하기

사이드 패널에서 캡처하기

캡처하려는 사이트에서 Kapture 아이콘을 클릭하세요. 전체 페이지 또는 영역 선택을 고르고 PNG, JPEG, PDF 중에서 선택합니다. 현재 브라우저는 사이드 패널 옆에 남은 페이지 너비를 사용합니다. 캡처가 진행되는 동안에는 해당 탭을 활성 상태로 두세요. 취소하면 캡처가 멈추고, 이미 저장된 이미지 조각은 그대로 남습니다.

영역 선택하기

영역 선택을 누르면 사이드 패널이 열린 채로 현재 페이지 위에 조작 버튼이 나타납니다. 자유형, 1:1, 16:9, 9:16 중에서 고른 뒤 페이지의 보이는 부분에서 드래그하세요. 캡처를 누르기 전에 선택 영역을 옮기거나 모서리를 끌어 크기를 조절할 수 있습니다. Kapture는 이미지를 찍기 전에 자체 조작 버튼을 숨깁니다. Escape 키로 취소합니다. 영역 캡처는 현재 브라우저 화면과 기기의 원래 화면 밀도를 사용하며, 보이는 화면을 넘어가지 않습니다.

뷰포트

현재 브라우저는 기기 본래의 스크린샷 밀도를 유지합니다. 휴대폰(390), 태블릿(820), 데스크톱(1440), 데스크톱(1920)은 캡처하는 동안 페이지를 해당 너비로 그린 뒤 원래대로 되돌립니다. 이 프리셋은 CSS 픽셀 하나당 이미지 픽셀 하나로 내보냅니다. 반응형 뷰포트 프리셋일 뿐, 실제 기기를 그대로 재현한 것은 아닙니다. Chrome이 디버깅 배너를 표시할 수 있으니 프리셋을 쓰기 전에 개발자 도구를 닫으세요.

Kapture는 본문 전체를 캡처하며 이미지 8,000행마다 나눕니다. 움직이는 콘텐츠는 각 구간에 도달한 시점의 모습으로 담기므로, 서로 다른 구간이 같은 순간에 캡처되는 것은 아닙니다.

캡처가 저장되는 위치

Kapture는 새 캡처를 항상 Chrome 다운로드 위치 안의 Kapture 폴더에 저장하며, Kapture에서는 Downloads/Kapture로 표시됩니다. 프로젝트 칸을 비워 두면 그 폴더에 바로 저장되고, 프로젝트 이름을 적으면 Downloads/Kapture/Research처럼 하위 폴더에 저장됩니다. 프로젝트는 폴더 한 단계이므로, 폴더 이름에 쓸 수 없는 슬래시 등의 문자는 하이픈으로 바뀝니다. 파일 이름은 사이트 이름과 일련번호로 지어지며 bbc_001.png과 같은 형태입니다.

다운로드 위치는 Chrome 설정에 지정된 폴더이며, 보통 다운로드 폴더입니다. 다른 곳에 저장하려면 Chrome에서 다운로드 위치를 바꾸세요.

PDF로 내보내기

PDF를 고르면 여러 쪽짜리 PDF 하나가 기기에 만들어집니다. 최대 8,000행씩 캡처된 각 구간이 PDF 한 쪽이 됩니다. 파일 크기를 적당히 유지하기 위해 내부적으로 JPEG 압축을 사용합니다. 이미지 파일이 더 편하다면 PNG와 JPEG도 그대로 쓸 수 있습니다.

기록

저장된 PNG 또는 JPEG 조각마다 간결한 기록이 하나씩 추가되고, 완성된 PDF도 하나의 기록이 됩니다. 기록은 최신순으로 한 쪽에 10개씩, 보관됨과 삭제됨 탭으로 나뉘어 표시됩니다. 열기를 누르면 컴퓨터의 기본 앱으로 파일이 열립니다. 카드를 하나씩 선택하거나 현재 탭에서 전체 선택한 뒤 휴지통을 누르고 대화상자에서 확인하면, 스크린샷 파일이 완전히 삭제되고 기록도 사라집니다. 새로 고침을 누르면 Chrome이 파일이 남아 있는지 다시 확인합니다.

Chrome의 파일 확인은 조금 늦을 수 있고, Chrome 밖에서 옮기거나 이름을 바꾼 파일은 더 이상 찾지 못할 수 있습니다. 기존 파일 이름을 덮어쓰는 일은 없으며, Chrome이 대신 뒤에 구분용 접미사를 붙입니다.

이미지 파일에 기록되는 정보

새로 만든 PNG와 JPEG 캡처에는 이미지 파일 안에 작은 기록이 담깁니다. 페이지 주소, 사이트 이름, 사용한 뷰포트, 캡처 방식, 캡처 시각입니다. 이 기록은 Mac용 Kapture Pro가 읽을 수 있도록 파일과 함께 이동하며, 기기에만 남습니다. 스크린샷을 받은 사람도 이 기록을 볼 수 있으니, 비공개 페이지의 캡처는 사진 자체를 다룰 때와 똑같이 신중하게 공유하세요.

권한

activeTab은 아이콘을 클릭한 뒤 일시적인 접근 권한을 줍니다. scripting은 페이지 캡처를 실행합니다. downloads는 Kapture의 파일을 저장하고 확인하고 삭제합니다. downloads.open은 기록에서 버튼을 눌렀을 때만 스크린샷을 엽니다. sidePanel은 인터페이스를 제공합니다. storage는 기기 내 기록과 폴더, 테마, 언어, 캡처 상태를 보관합니다. 디버거 권한은 뷰포트 프리셋을 적용하고 기기 크기의 이미지를 캡처하는 데 쓰이며, 처리된 오류가 발생한 경우를 포함해 작업이 끝나면 Kapture가 연결을 해제합니다. Kapture는 사이트에 대한 영구 접근 권한이나 방문 기록, 쿠키를 요청하지 않습니다.

제한 사항

Chrome 웹 스토어, 브라우저 설정, 일부 내장 뷰어를 비롯해 Chrome이 보호하는 페이지는 캡처할 수 없습니다. 영역 선택은 화면에 보이는 부분으로 제한됩니다. 따로 스크롤되는 패널, 가상화된 콘텐츠, 복잡한 고정 레이아웃은 추가 처리가 필요할 수 있습니다. 전체 페이지 캡처는 끝없이 이어지는 피드를 막기 위해 300화면에서 멈추며, 큰 이미지는 브라우저 메모리에 좌우됩니다.

개인정보

Kapture는 선택한 페이지의 보이는 픽셀과 레이아웃을 기기 안에서 처리합니다. 스크린샷, URL, 사이트 내용, 사용 데이터를 개발자나 제3자에게 보내지 않습니다. 전체 방침은 개인정보 페이지에서 확인할 수 있습니다.
