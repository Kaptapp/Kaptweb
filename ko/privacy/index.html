Kapture 개인정보처리방침

2026년 10월 29일 시행

당사 소개

Kapture는 KUMO STUDIO LIMITED가 만듭니다. KUMO STUDIO LIMITED는 잉글랜드 및 웨일스에 회사 번호 08453597로 등록된 비상장 유한회사(private limited company)이며, 등록 사무소는 Office 2, Tweed House, Park Lane, Swanley, Kent, BR8 8DT, England에 있습니다. 당사는 본 방침에서 설명하는 개인정보의 컨트롤러(controller)입니다.

요약

캡처는 기기에만 남습니다. 당사는 사용자의 스크린샷과 그 내용, 라이브러리, 프로젝트, 태그, 메모를 절대 받지 않습니다.

Chrome용 Kapture는 계정이 필요 없으며 당사에 아무것도 보내지 않습니다.

Kapture 계정에는 이메일 주소가 저장되며, Kapture Pro가 출시되면 라이선스와 사용자가 활성화한 기기도 저장됩니다.

당사는 광고, 분석, 추적을 사용하지 않으며 사용자의 데이터를 절대 판매하지 않습니다.

Chrome용 Kapture

Kapture가 처리하는 정보

사용자가 캡처를 시작하면 Kapture는 요청된 PNG, JPEG 또는 PDF 파일을 생성하기 위해 활성 웹페이지의 시각적 콘텐츠와 해당 주소를 처리합니다. Kapture는 파일 이름, 출처 웹사이트 호스트명, Chrome 다운로드 ID, 캡처 시각, 파일 사용 가능 여부를 포함한 제한된 스크린샷 기록 메타데이터를 Chrome 내에 로컬로 저장합니다. 또한 사용자가 선택한 테마와 다운로드 하위 폴더 설정도 로컬에 저장합니다.

정보의 이용 방식

해당 정보는 스크린샷을 생성하고 저장하며, 사용자가 선택한 화면 크기를 적용하고, 다운로드한 파일의 이름을 지정하며, 로컬 캡처 기록을 표시하고, 저장된 캡처를 열거나 삭제할 수 있도록 하는 목적으로만 사용됩니다.

로컬 저장 및 보관

스크린샷 파일은 Chrome의 다운로드 기능을 통해 사용자의 컴퓨터에 직접 저장됩니다. 기록 메타데이터와 환경설정은 Chrome 저장소를 사용해 로컬에 보관됩니다. 사용자는 Kapture에서 기록을 지울 수 있고, Kapture 또는 운영체제를 통해 스크린샷 파일을 삭제할 수 있습니다. 확장 프로그램을 삭제하면 Chrome의 동작에 따라 로컬 확장 데이터가 제거됩니다. 다운로드된 스크린샷 파일은 사용자가 삭제할 때까지 그대로 남습니다.

공유 및 전송

Kapture는 웹페이지 내용, 스크린샷, 브라우징 정보 또는 기록 메타데이터를 개발자나 외부 서버로 전송하지 않습니다. Kapture에는 분석, 광고, 추적 또는 제3자 데이터 서비스가 포함되어 있지 않습니다. 사용자 데이터는 제3자에게 판매되거나 이전되지 않습니다.

원격 코드

Kapture는 원격 코드를 내려받거나 실행하지 않습니다. 모든 실행 코드는 Chrome 웹 스토어를 통해 배포되는 확장 프로그램 패키지에 포함되어 있습니다.

Chrome 권한

Kapture는 사용자가 요청한 스크린샷 기능을 제공하기 위해서만 Chrome 권한을 사용합니다. 활성 탭 접근, 패키지에 포함된 캡처 컨트롤 삽입, 다운로드 저장 및 열기, 사이드 패널 표시, 로컬 환경설정 및 기록 저장, 선택한 반응형 화면 크기의 일시 적용이 이에 해당합니다.

Kapture 계정과 Kapture Pro

지금도 kaptapp.com/account에서 Kapture 계정을 만들고 로그인할 수 있습니다. Kapture Pro와 그 라이선스, 결제는 아직 제공되지 않습니다. 이 섹션에서 이들에 관한 부분은 제공이 시작된 뒤 당사가 해당 정보를 어떻게 처리할지 설명하며, 그 전에 달라지는 점이 있으면 본 방침을 업데이트합니다.

수집하는 정보와 수집 목적

계정 정보. 이메일 주소, 계정 ID, 가입 시각과 마지막 로그인 시각입니다. 당사는 이 정보를 계정 생성, 이메일로 보낸 링크를 통한 로그인, 계정 관련 연락에 사용합니다. 법적 근거: 사용자와의 계약 이행.

로그인 세션. 로그인한 각 세션에 대해 당사의 로그인 서비스 제공업체가 기록하는 IP 주소와 브라우저 정보입니다. 당사는 이 정보를 계정을 안전하게 보호하고 오용을 막는 데 사용합니다. 법적 근거: 보안에 관한 당사의 정당한 이익.

기기. Kapture Pro를 사용하는 경우: 앱이 생성한 식별자, 기기 이름, 플랫폼(macOS 또는 Windows), 앱 버전, 그리고 기기가 활성화된 시각, 마지막으로 라이선스를 확인한 시각, 비활성화된 시각입니다. 당사는 이 정보를 기기 2대 제한 적용, 라이선스 발급, 계정 페이지의 기기 표시에 사용합니다. 법적 근거: 사용자와의 계약 이행.

라이선스 및 체험. Kapture Pro 보유 여부, 요금제와 이용 기한, 무료 체험의 시작 시점과 종료 시점, 그리고 이메일 주소의 단방향 암호화 해시입니다. 당사는 이 정보를 라이선스 발급과 1인당 1회 무료 체험 제공에 사용합니다. 법적 근거: 사용자와의 계약 이행, 그리고 무료 체험의 반복 이용을 막는 데 대한 당사의 정당한 이익.

결제. Kapture Pro 요금을 결제하는 경우: Stripe 고객 ID와 구독 ID, 요금제, 가격, 상태, 갱신일과 해지일, 그리고 각 결제의 금액, 통화, 날짜, 환불 상태입니다. 당사는 이 정보를 결제한 만큼의 이용 권한을 제공하고 재무 기록을 보관하는 데 사용합니다. 법적 근거: 사용자와의 계약 이행, 그리고 회계 기록을 보관해야 하는 당사의 법적 의무.

사용자가 보낸 메시지. 당사는 메시지에 답변하는 데 이를 사용합니다. 법적 근거: 사용자에게 답변하는 데 대한 당사의 정당한 이익, 또는 메시지가 계정에 관한 것인 경우 사용자와의 계약.

컴퓨터에 저장되는 Kapture Pro 라이선스에는 계정 ID, 기기 식별자의 단방향 해시, 요금제와 유효 기간이 담겨 있습니다. 당사는 앱이 오프라인에서도 라이선스를 확인할 수 있도록 여기에 서명합니다.

수집하지 않는 정보

당사는 사용자의 스크린샷이나 PDF, 그 파일 이름이나 내용, 캡처한 페이지, 라이브러리, 프로젝트, 컬렉션, 태그, 메모, 검색 내용을 받지 않습니다. kaptapp.com, Chrome용 Kapture, Kapture Pro에는 광고, 분석, 추적이 포함되어 있지 않습니다.

Stripe를 통한 결제

결제는 Stripe(Stripe Payments Europe, Limited, 규제 대상 결제 서비스는 Stripe Payments UK Ltd)가 처리할 예정입니다. Stripe는 결제 정보와 청구지 주소를 수집하며, 사용자가 제공하는 경우 세금 식별 번호도 수집합니다. 당사는 전체 카드 번호나 보안 코드를 절대 받거나 저장하지 않습니다. Stripe는 사기 방지와 법적 의무 이행 등 자체 목적으로도 결제 정보를 사용하며, 이는 stripe.com/privacy의 Stripe 개인정보처리방침에 설명되어 있습니다.

당사를 위해 정보를 처리하는 업체

Supabase는 로그인 이메일을 포함한 계정 로그인, 당사의 계정 및 라이선스 데이터베이스, 라이선스를 발급하는 서비스를 운영합니다. 데이터는 유럽연합(아일랜드)에 저장됩니다. Supabase, Inc.는 미국에 소재하며 지원 제공을 위해 데이터에 접근할 수 있습니다.

Stripe는 위에서 설명한 대로 결제와 구독을 처리할 예정입니다.

GitHub Pages는 kaptapp.com을 호스팅하며, IP 주소 등 일반적인 웹 요청 정보를 수신합니다. GitHub Pages는 미국에 소재합니다.

정보가 영국 또는 유럽경제지역 밖으로 이전되는 경우, 당사는 영국 적정성 규정, 영국–미국 데이터 브리지, EU–미국 데이터 프라이버시 프레임워크, 표준계약조항 등 이들 업체가 제공하는 보호 조치에 의존합니다.

보관 기간

계정 정보, 로그인 세션, 기기 기록(비활성화한 기기 포함)은 계정이 존재하는 동안 보관되며 계정을 삭제하면 함께 삭제됩니다.

이메일 주소의 해시를 포함한 체험 기록은 같은 이메일 주소로 체험을 다시 신청할 수 없도록, 계정을 삭제한 뒤에도 당사가 무료 체험을 제공하는 동안 보관됩니다. 이 해시는 원래 이메일 주소로 되돌릴 수 없습니다.

결제 기록은 Stripe가 보관하며, 당사는 영국 법률이 회계 목적으로 요구하는 결제 기록을 일반적으로 6년간 보관합니다.

Stripe에서 받은 결제 알림 기록에는 결제 정보가 아니라 Stripe ID와 처리 상태가 담기며, 해당 알림을 처리하고 확인하는 데 필요한 동안 보관됩니다.

kaptapp.com의 브라우저 저장소

계정 페이지는 로그인 상태가 유지되도록 로그인 세션을 브라우저의 로컬 저장소에 보관합니다. 이는 페이지가 작동하는 데 필요하며 로그아웃하면 삭제됩니다. kaptapp.com은 광고 또는 분석 쿠키를 설정하지 않습니다.

계정 삭제

계정에 등록된 이메일 주소로 당사에 메일을 보내 주시면 계정, 로그인 세션, 기기 기록을 삭제해 드립니다. 위에서 설명한 체험 기록과 결제 기록은 보관됩니다. 계정을 삭제해도 컴퓨터에 있는 것은 아무것도 삭제되지 않습니다.

사용자의 권리

사용자는 당사에 개인정보 사본을 요청할 수 있으며, 개인정보의 정정 또는 삭제, 이용 제한, 또는 사용자가 제공한 데이터를 이동 가능한 형식으로 제공해 줄 것을 요청할 수 있습니다. 당사의 정당한 이익에 근거한 이용에 대해서는 이의를 제기할 수 있습니다. 당사는 1개월 이내에 답변합니다.

당사의 데이터 처리 방식에 만족하지 않으시면 먼저 당사에 알려 주세요. 영국 정보위원회(Information Commissioner’s Office, ico.org.uk)에 민원을 제기할 수도 있으며, 유럽연합에 거주하는 경우에는 거주 국가의 데이터 보호 기관에 민원을 제기할 수 있습니다.

아동

Kapture 계정은 16세 미만(현지 법률이 더 높은 연령을 요구하는 경우 해당 연령 미만)인 사람을 대상으로 하지 않으며, 당사는 이들의 계정을 알면서 생성하지 않습니다.

본 방침의 변경

Kapture의 데이터 처리 방식이 변경되는 경우, 변경된 기능이 출시되기 전에 본 방침과 Chrome 웹 스토어 고지 내용이 업데이트됩니다.

변경 사항이 계정 보유자의 데이터 이용 방식에 중대한 영향을 미치는 경우, 당사는 변경 사항이 시행되기 전에 이메일로 알립니다.
