Chrome 확장 프로그램 0.4.7 · Mac용 Kapture Pro

Chrome에서 캡처.
Mac에서 정리.

Kapture는 Chrome에서 바로 웹페이지 전체나 원하는 영역을 캡처합니다. Kapture Pro는 그 캡처들을 Mac 안의 시각적 라이브러리로 만들어 줍니다.

Chrome 120 이상이 필요합니다. Chrome용 Kapture는 무료이고, Mac용 Kapture Pro는 곧 출시됩니다.

Chrome용 Kapture · 0.4.7

전체를, 아니면
원하는 부분만.

두 가지 캡처 방식, 네 가지 저장 위치, 그리고 기기를 떠나는 것은 아무것도 없습니다.

전체 페이지

Kapture가 문서를 처음부터 끝까지 스크롤하며 캡처합니다. 아주 긴 페이지는 8,000픽셀 단위로 나눠 파일을 다루기 쉽게 유지합니다.

영역 선택

보이는 화면에서 드래그해 원하는 영역을 지정하세요. 자유 비율, 1:1, 16:9, 9:16 중에서 고르고 캡처 전에 위치와 크기를 조정할 수 있습니다.

확장 프로그램 안에는

정말 필요했던 그 스크린샷을 위해.

PNG, JPEG, PDF

캡처하기 전에 형식을 고르세요. PDF는 여러 페이지가 담긴 파일 하나로 저장됩니다.

화면 크기 프리셋

지금 창 크기 그대로 찍거나, 휴대폰 390, 태블릿 820, 데스크톱 1440·1920 너비로 페이지를 다시 그린 뒤 찍을 수 있습니다.

프로젝트 폴더

페이지나 프로젝트별로 폴더 이름을 정하세요. 캡처가 순서대로 쌓이고, Kapture Pro가 바로 이어받습니다.

미리보기가 있는 기록

최신 항목이 위에, 미리보기와 사이트, 시간까지 함께. 캡처를 바로 열거나 여러 개를 골라 완전히 삭제할 수 있습니다.

라이트와 다크

사이드 패널은 두 테마를 모두 지원하고, 고른 테마를 기억합니다.

기기 안에서만

계정도, 광고도, 분석도 없습니다. 캡처는 내 기기에서 만들어지고 그대로 남습니다.

Mac용 Kapture Pro

흩어져 있던 스크린샷,
드디어 정리됩니다.

Kapture Pro는 이미 Mac에 저장된 스크린샷을 색인해 검색할 수 있는 시각적 작업 공간으로 만들어 줍니다.

  • 프로젝트

    캡처 폴더 하나하나가 오가며 작업할 수 있는 프로젝트가 됩니다.

  • 검색

    Finder를 열지 않고도 이름, 사이트, 프로젝트로 캡처를 찾을 수 있습니다.

  • 시각 라이브러리

    파일 이름이 아니라 미리보기로 전체를 훑어봅니다.

  • 인스펙터

    고른 항목의 크기, 형식, 출처, 캡처 시각을 바로 확인합니다.

  • 태그와 메모

    직접 맥락을 남겨 두면 나중에 봐도 무슨 캡처인지 알 수 있습니다.

  • 로컬 저장

    클라우드도, 동기화도, 계정도 없습니다. 이미 있는 디스크를 읽을 뿐입니다.

파일은 원래 있던 자리에 그대로 있습니다.
Kapture Pro는 그것을 찾고 정리하도록 도울 뿐입니다.

사용 방법

Chrome이 캡처하고,
Mac이 정리합니다.

  1. 캡처

    Chrome에서

    사이드 패널을 열고 전체 페이지나 영역을 고른 뒤, 프로젝트 폴더를 지정합니다.

  2. 저장

    내 Mac에

    파일은 Downloads/Kapture/ 아래 해당 프로젝트로 바로 들어가며, 순서대로 이름이 붙습니다.

  3. 정리

    Kapture Pro에서

    같은 폴더가 검색 가능한 라이브러리로 열려 훑어보고, 태그를 달고, 비교할 수 있습니다.

개인정보

기본이 로컬입니다.

Kapture는 사용자의 컴퓨터에서 스크린샷을 만들고 Chrome의 다운로드 기능으로 저장합니다. Kapture Pro는 이미 Mac에 있는 파일을 읽습니다. 업로드되는 것은 없고, 두 제품 모두 계정이 필요 없으며, 분석·광고·추적도 들어 있지 않습니다.

  • No account required
  • No analytics or tracking
  • No remote code
  • 클라우드 저장 없음
