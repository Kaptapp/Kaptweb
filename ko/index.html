Chrome 확장 프로그램 0.4.7 · Mac용 Kapture Pro

Chrome에서 캡처.
Mac에서 정리.

Kapture는 Chrome에서 바로 전체 웹페이지나 선택한 영역을 저장합니다. Kapture Pro는 그것들을 Mac 안에서 정돈되고 검색 가능한 시각적 라이브러리로 만듭니다.

Chrome에 추가 Mac용 Kapture Pro 캡처하는 모습 보기

Chrome 120 이상이 필요합니다. Chrome용 Kapture는 무료이고, Mac용 Kapture Pro는 곧 출시됩니다.

사용 방법

세 단계. 설정은 없습니다.

  1. 1

    페이지 열기

    남겨두고 싶은 화면으로 이동하세요.

  2. 2

    Kapture 클릭

    페이지 옆에 사이드 패널이 열립니다.

  3. 3

    캡처

    전체 페이지나 영역을 고르고 저장하세요.

Chrome용 Kapture · 0.4.7

전체를, 아니면
원하는 부분만.

웹페이지 전체를 캡처하거나 필요한 영역만 정확히 선택하세요. PNG, JPEG, PDF로 로컬에 저장됩니다.

  • 전체 페이지

    Kapture가 페이지를 위에서 아래까지 스크롤해 웹페이지 전체를 저장합니다.

  • 영역 선택

    필요한 부분만 정확히 드래그해서 그 부분만 저장합니다.

확장 프로그램 안에는

정말 필요했던
그 스크린샷을 위해.

PNG, JPEG, PDF

캡처하기 전에 형식을 고르세요. PDF는 여러 페이지가 담긴 파일 하나로 저장됩니다.

화면 크기 프리셋

지금 창 크기 그대로 찍거나, 휴대폰 390, 태블릿 820, 데스크톱 1440·1920 너비로 페이지를 다시 그린 뒤 찍을 수 있습니다.

프로젝트 폴더

페이지나 프로젝트별로 폴더 이름을 정하세요. 캡처가 순서대로 쌓이고, Kapture Pro가 바로 이어받습니다.

미리보기가 있는 기록

최신 항목이 위에, 미리보기와 사이트, 시간까지 함께. 캡처를 바로 열거나 여러 개를 골라 완전히 삭제할 수 있습니다.

라이트와 다크

사이드 패널은 두 테마를 모두 지원하고, 고른 테마를 기억합니다.

기기 안에서만

계정도, 광고도, 분석도 없습니다. 캡처는 내 기기에서 만들어지고 그대로 남습니다.

  • No analytics or tracking
  • No remote code
  • 클라우드 저장 없음
