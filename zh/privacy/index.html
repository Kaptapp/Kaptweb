Kapture 隐私政策

自 2026 年 10 月 29 日起生效

我们是谁

Kapture 由 KUMO STUDIO LIMITED 开发。KUMO STUDIO LIMITED 是一家在英格兰和威尔士注册的私人有限公司，公司编号为 08453597，注册办公地址为 Office 2, Tweed House, Park Lane, Swanley, Kent, BR8 8DT, England。我们是本政策所述个人数据的控制者。

简要说明

你的截图保留在你的设备上。我们绝不会接收你的截图及其内容，也不会接收你的资料库、项目、标签或备注。

Chrome 版 Kapture 无需账户，也不会向我们发送任何信息。

Kapture 账户保存你的电子邮件地址；Kapture Pro 推出后，还会保存你的许可证以及你激活的设备。

我们不使用广告、分析或追踪，也绝不出售你的数据。

Chrome 版 Kapture

Kapture 处理的信息

当用户发起截图时，Kapture 会处理当前网页的可见内容及其网址，以生成所请求的 PNG、JPEG 或 PDF 文件。Kapture 会在 Chrome 本地存储有限的截图历史元数据，包括文件名、来源网站主机名、Chrome 下载 ID、截图时间和文件可用状态。它还会在本地存储用户选择的主题和下载子文件夹设置。

信息的使用方式

这些信息仅用于创建和保存截图、应用用户选择的画面宽度、为下载的文件命名、显示本地截图记录，以及让用户打开或删除已保存的截图。

本地存储与保留

截图文件通过 Chrome 的下载功能直接保存到用户的电脑上。历史元数据和偏好设置使用 Chrome 存储保存在本地。用户可以在 Kapture 中清除记录，并通过 Kapture 或操作系统删除截图文件。卸载扩展程序时会移除其本地数据，具体取决于 Chrome 的行为。已下载的截图文件会一直保留，直到用户自行删除。

共享与传输

Kapture 不会将网页内容、截图、浏览信息或历史元数据发送给开发者或外部服务器。Kapture 不含分析、广告、追踪或第三方数据服务。用户数据不会被出售或转让给第三方。

远程代码

Kapture 不会下载或执行远程代码。所有可执行代码都包含在通过 Chrome 应用商店分发的扩展程序包中。

Chrome 权限

Kapture 使用 Chrome 权限仅为实现用户主动发起的截图功能：访问当前标签页、注入随扩展程序打包的截图控件、保存和打开下载内容、显示侧边栏、在本地存储偏好设置和记录，以及临时应用所选的响应式画面宽度。

你的 Kapture 账户和 Kapture Pro

你现在已经可以在 kaptapp.com/account 创建 Kapture 账户并登录。Kapture Pro 及其许可证和付款功能尚未推出。本节中与它们相关的内容，说明的是它们推出后我们将如何处理相关信息；如果在此之前有任何变化，我们会更新本政策。

我们收集哪些信息及原因

账户信息。你的电子邮件地址、账户 ID，以及你注册和最近一次登录的时间。我们使用这些信息来创建你的账户、通过电子邮件发送的链接让你登录，并就你的账户与你联系。法律依据：履行我们与你之间的合同。

登录会话。每个已登录会话中，由我们的登录服务提供商记录的 IP 地址和浏览器信息。我们使用这些信息来保障账户安全并防止滥用。法律依据：我们在安全方面的正当利益。

设备。当你使用 Kapture Pro 时：应用生成的标识符、设备名称、平台（macOS 或 Windows）、应用版本，以及设备的激活时间、最近一次检查许可证的时间和停用时间。我们使用这些信息来执行两台设备的限制、签发许可证，并在你的账户页面上显示你的设备。法律依据：履行我们与你之间的合同。

许可证和试用。你是否拥有 Kapture Pro、使用哪种方案及有效期至何时、免费试用的开始和结束时间，以及你的电子邮件地址的单向加密哈希值。我们使用这些信息来签发许可证，并为每人提供一次免费试用。法律依据：履行我们与你之间的合同，以及我们在防止重复免费试用方面的正当利益。

付款。当你为 Kapture Pro 付款时：你的 Stripe 客户 ID 和订阅 ID、方案、价格、状态、续订和取消日期，以及每笔付款的金额、币种、日期和退款状态。我们使用这些信息来为你提供你所付费的使用权限，并保存财务记录。法律依据：履行我们与你之间的合同，以及我们保存会计记录的法定义务。

你发给我们的消息。我们使用这些消息来回复你。法律依据：我们在回复你方面的正当利益；如果消息与你的账户有关，则为我们与你之间的合同。

保存在你电脑上的 Kapture Pro 许可证包含你的账户 ID、设备标识符的单向哈希值、你的方案及其有效日期。我们会对许可证进行签名，以便应用在离线状态下验证它。

我们不收集的信息

我们不会接收你的截图或 PDF、它们的文件名或内容、你截取的页面，也不会接收你的资料库、项目、合集、标签、备注或搜索内容。kaptapp.com、Chrome 版 Kapture 和 Kapture Pro 均不含广告、分析或追踪。

通过 Stripe 付款

付款将由 Stripe 处理（Stripe Payments Europe, Limited，受监管的支付服务则由 Stripe Payments UK Ltd 提供）。Stripe 会收集你的付款信息和账单地址，如果你提供了税号，也会收集你的税号。我们绝不会接收或存储你的完整卡号或安全码。Stripe 还会将付款信息用于其自身目的，例如防范欺诈和履行其法定义务，详见其隐私政策 stripe.com/privacy。

为我们处理信息的服务商

Supabase 负责运行账户登录（包括登录邮件）、我们的账户和许可证数据库，以及签发许可证的服务。这些数据存储在欧盟（爱尔兰）。Supabase, Inc. 位于美国，可能会为提供支持而访问数据。

Stripe 将按上文所述处理付款和订阅。

GitHub Pages 托管 kaptapp.com，并会接收标准的网络请求信息，例如 IP 地址。它位于美国。

当信息被传输到英国或欧洲经济区以外时，我们依靠这些服务商提供的保障措施，例如英国充分性认定条例、英国–美国数据桥、欧盟–美国数据隐私框架或标准合同条款。

保存期限

账户信息、登录会话和设备记录（包括你已停用的设备）会在你的账户存续期间保留，并在账户删除时一并删除。

试用记录（包括你的电子邮件地址的哈希值）在你的账户删除后仍会保留，只要我们仍提供免费试用就会一直保留，以防同一电子邮件地址再次申领试用。该哈希值无法还原为你的电子邮件地址。

付款记录由 Stripe 保存；我们也会按照英国法律对会计的要求保存付款记录，保存期限一般为六年。

来自 Stripe 的付款通知记录包含 Stripe ID 和处理状态，不含付款信息，并会在我们处理和核对这些通知所需的期间内保留。

kaptapp.com 上的浏览器存储

账户页面会将你的登录会话保存在浏览器的本地存储中，以便你保持登录状态。这是页面正常运行所必需的，并会在你退出登录时删除。kaptapp.com 不设置任何广告或分析 Cookie。

删除账户

请使用你账户中的电子邮件地址给我们发送邮件，我们将删除你的账户、登录会话和设备记录。我们会保留上文所述的试用记录和付款记录。删除账户不会删除你电脑上的任何内容。

你的权利

你可以要求我们提供你的个人数据副本，也可以要求我们更正或删除这些数据、限制我们对其的使用，或以可移植的格式向你提供你所提供的数据。你可以反对我们基于正当利益对数据的使用。我们会在一个月内答复。

如果你对我们处理你数据的方式不满意，请先告诉我们。你也可以向英国信息专员办公室（Information Commissioner’s Office，ico.org.uk）投诉；如果你居住在欧盟，也可以向你所在国家的数据保护机构投诉。

儿童

Kapture 账户不面向 16 岁以下的人士（如当地法律规定了更高年龄，则以该年龄为准），我们也不会在知情的情况下为他们创建账户。

本政策的变更

如果 Kapture 的数据处理方式发生变化，本政策及 Chrome 应用商店中的相关说明将在变更后的功能发布之前更新。

如果某项变更会对我们使用账户持有人数据的方式产生重大影响，我们会在变更生效前通过电子邮件通知他们。

联系方式

如有隐私或支持方面的问题，请发送邮件至 联系。
