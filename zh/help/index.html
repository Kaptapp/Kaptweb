最新更新

版本 0.4.9

当前版本

发布于 2026 年 9 月 29 日

侧边栏的动效现在和 Mac 版 Kapture Pro 一致。切换捕获模式、打开设置或翻看历史记录都会自己说明变化，而且一切依然轻快。

  • 选中状态会跟着你移动。在整页和选择区域之间切换，或者在保留和已删除之间切换时，同一个高亮块会滑动过去，而不是从一个按钮直接跳到另一个。
  • 过渡更顺滑，涵盖捕获模式、设置、历史记录和翻页。翻页时的动效会跟着你前进的方向。
  • 更细致的动效，用于状态提示、删除对话框和 Kapture Pro 提示卡片。
  • 主题切换更柔和，按钮也有了轻微的按压反馈。
  • 尊重“减弱动态效果”设置。如果你的系统要求减少动效，过渡会变成短暂的淡入淡出，不再有滑动。所有功能照常使用。
  • 快速而克制。没有任何弹跳效果，历史记录也不会让每一行依次逐个出现。
  • 包含设置中最新的改动：语言和帮助两行及其图标，以及本站多语言的帮助和隐私页面。

以往的更新

版本 0.4.8 2026 年 9 月 25 日

Kapture 现在支持五种语言，历史记录会把仍保留的截图和已消失的记录分开，而且每张新截图都会带上一小段关于拍摄方式的记录。

  • 五种语言。侧边栏支持 English、Español、简体中文、한국어 和 日本語。
  • 语言设置。设置中新增了语言选项。默认跟随浏览器语言，你选择的语言会被记住。
  • 历史记录分为“保留”和“已删除”两个标签页。文件仍在设备上的截图与文件已消失的记录分开显示。
  • 历史记录每页显示十条，之前是六条。
  • 成功提示会自动消失，几秒后自动清除。错误和警告会一直显示，直到被其他消息替换。
  • 图片内含截图记录。新的 PNG 和 JPEG 截图会在文件内部记录页面地址、网站名称、视口、截图类型和截图时间。这些信息只保存在你的设备上。
  • 修复“当前浏览器”的视口记录。现在记录的是页面实际渲染时的布局宽度，带有可见滚动条的页面不会再被记成宽出几个像素。
  • Kapture Pro 提示卡片。介绍 Mac 版 Kapture Pro 的提示，可以随时关闭，并附有 kaptapp.com 的链接。
  • 页脚更清爽。设置和隐私在左侧，kaptapp.com 在右侧。
  • 视口标签直接显示设备名称，不再重复标注像素宽度。
  • 更接近 Kapture Pro。面板间距、控件和历史卡片与 Mac 应用保持一致，页眉和页脚带有淡淡的 Kapture 青色。
  • 对比度更好。浅色模式下的次要文字已加深，达到 4.5:1 的对比度。

使用 Kapture

从侧边栏截图

在想要截图的网站上点击 Kapture 图标。选择整页或选择区域，以及 PNG、JPEG 或 PDF。当前浏览器使用侧边栏旁边可用的页面宽度。截图过程中请保持该标签页处于活动状态。取消会停止截图，已经保存的图片部分会保留。

选择一个区域

选择区域会在当前网页上显示控件，同时侧边栏保持可见。选择自由、1:1、16:9 或 9:16，然后在页面可见部分拖动。按下捕获前，可以移动选区或从角落调整大小。Kapture 会在拍摄前隐藏自己的控件。按 Escape 取消。区域截图使用当前浏览器视图和屏幕原生像素密度，不会超出可见范围。

视口

当前浏览器会保留截图的原生像素密度。手机 (390)、平板 (820)、桌面 (1440) 和桌面 (1920) 会在截图时按所选宽度渲染页面，之后再恢复。这些预设按每个 CSS 像素对应一个图片像素导出。它们是响应式视口预设，并不是实体设备的精确复制。Chrome 可能会显示调试提示条，因此使用预设前请先关闭开发者工具。

Kapture 会截取整个主文档，每 8,000 行图像分割一次。动态内容按到达每个区块时的样子截取，因此不同区块并不是在同一瞬间拍下的。

截图保存在哪里

Kapture 始终把新截图保存在 Chrome 下载位置中的 Kapture 文件夹里，在 Kapture 中显示为 Downloads/Kapture。项目字段留空即可直接保存在该文件夹，或者填写项目名称保存到子文件夹，例如 Downloads/Kapture/Research。项目只对应一层文件夹，因此斜杠和其他文件夹名称不允许的字符会替换成连字符。文件按网站名称加连续编号命名，例如 bbc_001.png。

下载位置由 Chrome 设置决定，通常是你的下载文件夹。想保存到别处，请在 Chrome 中修改下载位置。

导出 PDF

PDF 会在本地生成一个多页 PDF。每段最多 8,000 行的截图内容会成为一页 PDF。页面内部使用 JPEG 压缩，以保持文件大小实用。如果更需要图片文件，仍然可以选择 PNG 和 JPEG。

历史记录

每保存一段 PNG 或 JPEG 都会新增一条简洁的历史记录，一个完整的 PDF 也算一条。历史记录按时间从新到旧排列，每页十条，分为“保留”和“已删除”两个标签页。打开会用电脑的默认应用启动可用的文件。你可以逐个选择卡片，或在当前标签页中全选，然后点击垃圾桶并在对话框中确认，即可永久删除截图文件并移除对应记录。刷新会让 Chrome 重新检查文件是否仍然可用。

Chrome 检查文件是否存在可能会有延迟，在 Chrome 之外移动或重命名的文件可能就找不到了。已有的文件名永远不会被覆盖：Chrome 会另外加上一个后缀。

图片文件记录了什么

新的 PNG 和 JPEG 截图会在图片文件内部带上一小段记录：页面地址、网站名称、所用视口、截图类型和截图时间。它随文件一起保存，供 Mac 版 Kapture Pro 读取，并且只留在你的设备上。收到截图的人也能读到这段记录，因此分享私密页面的截图时，请像对待图片本身一样谨慎。

权限

activeTab 在你点击图标后授予临时访问权限。scripting 用于执行页面截图。downloads 用于保存、检查和删除 Kapture 的文件。downloads.open 只在你点击历史记录中的按钮后才打开截图。sidePanel 提供界面。storage 保存本地历史记录、文件夹、主题、语言和截图状态。调试权限用于应用视口预设并截取设备尺寸的图片，Kapture 会在结束后断开连接，遇到已处理的错误时同样如此。Kapture 不会请求永久的网站访问权限、浏览历史或 Cookie。

限制

受 Chrome 保护的页面无法截图，包括 Chrome 应用商店、浏览器设置和部分内嵌查看器。区域选择只限于页面可见部分。独立滚动面板、虚拟化内容和复杂的吸顶布局可能需要额外处理。整页截图最多到 300 屏，以避免无限信息流，而大图能否生成取决于浏览器内存。

隐私

Kapture 在你的设备上处理所选页面的可见像素和布局。截图、网址、网站内容和使用数据都不会发送给开发者或第三方。完整政策见隐私页面。
