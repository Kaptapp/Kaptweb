Chrome 拡張機能 0.4.7 · Mac 版 Kapture Pro

Chrome で撮る。
Mac で整理する。

Kapture は Chrome から直接、ページ全体でも選んだ範囲でもキャプチャします。 Kapture Pro は、それを Mac の中のビジュアルライブラリに変えます。

Chrome に追加 Mac 版 Kapture Pro 使い方を見る

Chrome 120 以降が必要です。Chrome 版 Kapture は無料。Mac 版 Kapture Pro は近日公開です。

Chrome 版 Kapture · 0.4.7

ページ全体か、
必要な一部だけか。

2 つのキャプチャ方法と 4 つの保存先。端末の外に出るものはありません。

ページ全体

Kapture がドキュメントをスクロールして最初から最後まで撮影します。とても長い ページは 8,000 ピクセルごとに分割するので、ファイルが扱いやすいままです。

範囲を選ぶ

表示中の画面をドラッグして範囲を指定します。フリー、1:1、16:9、9:16 から選び、 撮影前に位置やサイズを調整できます。

拡張機能の中身

本当に必要だったスクリーンショットのために。

PNG・JPEG・PDF

撮影前に形式を選べます。PDF は複数ページをまとめた 1 つのファイルになります。

画面幅プリセット

今のウィンドウのまま撮るか、スマホ 390・タブレット 820・デスクトップ 1440 / 1920 の幅で表示し直してから撮れます。

プロジェクトフォルダ

ページやプロジェクトごとにフォルダ名を決めます。キャプチャは順番に保存され、Kapture Pro がそのまま読み込めます。

プレビュー付きの履歴

新しい順に、プレビューとサイト名、時刻つきで。その場で開くことも、選んでまとめて削除することもできます。

ライトとダーク

サイドパネルは両方のテーマに対応し、選んだほうを覚えています。

ローカル完結

アカウントも広告も解析もありません。キャプチャは自分の端末で作られ、そこに残ります。

Mac 版 Kapture Pro

散らばったスクリーンショットが、
やっと整理される。

Kapture Pro は、すでに Mac に保存されているスクリーンショットを取り込み、 検索できるビジュアルな作業スペースに変えます。

  • プロジェクト

    キャプチャのフォルダが、そのまま行き来できるプロジェクトになります。

  • 検索

    Finder を開かなくても、名前・サイト・プロジェクトからキャプチャを探せます。

  • ビジュアルライブラリ

    ファイル名ではなくプレビューで全体を見渡せます。

  • インスペクタ

    選んだものの大きさ、形式、取得元、撮影日時をその場で確認できます。

  • タグとメモ

    自分で文脈を書き添えておけば、後から見ても用途がわかります。

  • ローカル保存

    クラウドも同期もアカウントも不要。手元のディスクを読むだけです。

ファイルは元の場所にあるままです。
Kapture Pro は、それを見つけて整理する手助けをするだけです。

使い方

Chrome が撮って、
Mac が整える。

  1. 撮る

    Chrome で

    サイドパネルを開き、ページ全体か範囲を選んで、保存先のプロジェクトを決めます。

  2. 保存

    Mac に

    ファイルは Downloads/Kapture/ のプロジェクトへ直接、連番で保存されます。

  3. 整理

    Kapture Pro で

    同じフォルダが、見渡して・タグを付けて・見比べられるライブラリとして開きます。

プライバシー

はじめからローカル。

Kapture はあなたのパソコン上でスクリーンショットを作り、Chrome のダウンロード機能で 保存します。Kapture Pro は、すでに Mac にあるファイルを読むだけです。アップロードは 一切なく、どちらの製品もアカウント不要で、解析・広告・トラッキングも含まれていません。

  • No account required
  • No analytics or tracking
  • No remote code
  • クラウド保存なし
