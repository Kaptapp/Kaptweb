Extensión de Chrome 0.4.7 · Kapture Pro para Mac

Captura en Chrome.
Organiza en Mac.

Kapture guarda páginas web completas o el área que elijas, directamente desde Chrome. Kapture Pro las convierte en una biblioteca visual ordenada y con búsqueda en tu Mac.

Añadir a Chrome Kapture Pro para Mac

Requiere Chrome 120 o posterior. Kapture para Chrome es gratis. Kapture Pro para Mac llega pronto.

Cómo funciona

Tres pasos.
Sin configurar nada.

  1. 1

    Abre la página

    Ve a la página que quieras guardar.

  2. 2

    Haz clic en Kapture

    El panel lateral se abre junto a la página.

  3. 3

    Captura

    Elige toda la página o solo una zona, y guarda.

Kapture para Chrome · 0.4.7

Captura todo.
O exactamente una parte.

Captura una página web completa o selecciona justo el área que necesitas. Guárdala en local como PNG, JPEG o PDF.

  • Página completa

    Guarda la página entera en tu proyecto. Las páginas largas se dividen cada 8.000 píxeles.

  • Selecciona un área

    Dibuja justo sobre lo que necesitas. Guarda solo esa zona.

En la extensión

Hecho para la captura
que de verdad necesitabas.

PNG, JPEG o PDF

Elige el formato antes de capturar. El PDF se genera como un único archivo local de varias páginas.

Tamaños de pantalla

Captura con el tamaño actual de tu ventana o muestra antes la página a 390 (móvil), 820 (tablet), 1440 o 1920 (escritorio).

Carpetas por proyecto

Ponle nombre a una carpeta por página o proyecto. Las capturas van ahí en orden, listas para que Kapture Pro las recoja.

Historial con vista previa

Lo más reciente primero, con vista previa, el sitio y la hora. Abre una captura o selecciona varias y bórralas definitivamente.

Claro y oscuro

El panel lateral tiene los dos temas y recuerda el que elijas.

Solo en local

Sin cuenta, sin anuncios, sin analíticas. Las capturas se hacen en tu equipo y ahí se quedan.

Privacidad

En local por defecto.

Kapture crea las capturas en tu ordenador y las guarda con el sistema de descargas de Chrome. Kapture Pro lee los archivos que ya están en tu Mac. No se sube nada, ninguno de los dos necesita cuenta y ninguno incluye analíticas, publicidad ni seguimiento.

  • No account required
  • No analytics or tracking
  • No remote code
  • Sin almacenamiento en la nube
