Extensión de Chrome · versión 0.4.4

Captura páginas enteras.
No solo lo que se ve.

Kapture es una extensión de Chrome para capturar páginas completas: recorre todo el documento, no solo lo que ves en pantalla. Guárdalas en PNG, JPEG o PDF, directo a tu carpeta de descargas.

Añadir a Chrome Añadir a Mac Ver cómo funciona

Requiere Chrome 120 o posterior. Tus capturas nunca salen de tu dispositivo. La app para Mac llega pronto.

Dos formas de capturar

Todo, o justo
la parte que quieras.

Páginas completas

Kapture recorre el documento y lo captura de principio a fin. Las páginas muy largas se dividen en secciones de 8.000 píxeles para que los archivos sigan siendo manejables.

Seleccionar zona

Arrastra sobre la parte visible para marcar una zona. Elige formato libre, 1:1, 16:9 o 9:16, y mueve o ajusta la selección antes de capturar.

Lo que incluye

Pensado para capturar lo que de verdad necesitas.

PNG, JPEG o PDF

Elige el formato antes de capturar. El PDF se genera como un único archivo local de varias páginas.

Tamaños de pantalla

Captura con el tamaño actual de tu ventana o muestra antes la página a 390 (móvil), 820 (tablet), 1440 o 1920 (escritorio).

Guarda donde tenga sentido

Envía las capturas directamente a Descargas o crea una carpeta por página o proyecto para tenerlo todo ordenado.

Historial local

Lo más reciente primero, con el sitio y la hora. Abre una captura o selecciona varias y bórralas definitivamente.

Claro y oscuro

El panel lateral tiene los dos temas y recuerda el que elijas.

Sin registros

Sin cuenta, sin anuncios, sin analíticas. Instálalo y captura.

Cómo funciona

Tres pasos. Sin configurar nada.

  1. 1

    Abre la página

    Ve a la página que quieras guardar.

  2. 2

    Haz clic en Kapture

    El panel lateral se abre junto a la página.

  3. 3

    Captura

    Elige toda la página o solo una zona, y guarda.

Privacidad

Tus capturas
se quedan en tu dispositivo.

Kapture procesa la página en tu ordenador y guarda el archivo con el sistema de descargas de Chrome. Ni las capturas, ni el contenido de las páginas, ni las URL, ni el historial se envían al desarrollador ni a terceros, y Kapture no incluye analíticas, publicidad ni seguimiento.

  • Sin cuenta
  • Sin analíticas ni seguimiento
  • Sin código remoto
  • Los archivos se guardan en tu equipo
